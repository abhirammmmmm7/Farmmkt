# 🌾 FarmMKT

Hi! 👋 Welcome to **FarmMKT**.

I built this project to make buying and selling farm products easier. The idea is simple—farmers should be able to list their products online, and customers should be able to browse, add items to their cart or wishlist, and explore products without unnecessary complexity.

This project also helped me gain hands-on experience with **Django**, database design, authentication, CRUD operations, and building a complete full-stack web application.

---

# ✨ Features

### 👨‍🌾 Farmer

* Register & Login
* Manage profile
* Add new products
* Edit products
* Delete products
* Upload product images
* View all products added by the farmer

### 🛒 Customer

* Register & Login
* Browse products
* View product details
* Add products to Cart
* Add products to Wishlist
* Remove products from Cart/Wishlist

### 🔐 Authentication

* Secure Login & Registration
* Session-based Authentication
* User Role Separation

# 🚀 Installation

## 1. Clone the Repository

```bash
git clone https://github.com/abhirammmmmm7/FarmMKT.git
```

---

## 2. Move into the Project Directory

```bash
cd FarmMKT
```

---

## 3. Create a Virtual Environment

### Windows

```bash
python -m venv venv
```

### Linux/macOS

```bash
python3 -m venv venv
```

---

## 4. Activate the Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux/macOS

```bash
source venv/bin/activate
```

---

## 5. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 6. Apply Database Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

---

## 7. Create a Superuser (Optional)

```bash
python manage.py createsuperuser
```

Follow the prompts to create your admin account.

---

## 8. Run the Development Server

```bash
python manage.py runserver
```

Open your browser and visit:

```
http://127.0.0.1:8000/
```
